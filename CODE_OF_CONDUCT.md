# Code de conduite

Ce projet adopte le **Contributor Covenant, version 2.1**, dans son intégralité.
Le texte de référence, ainsi que ses traductions, sont consultables ici :

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/

Il s'applique à tous les espaces du projet — issues, pull requests, discussions,
messages de commit — et aux situations où quelqu'un représente le projet
publiquement.

## En bref

Comportez-vous de façon à ce que quelqu'un qui débute ait envie de poser sa
question. Le désaccord technique est normal et bienvenu ; le mépris ne l'est
pas. Une critique porte sur le code, jamais sur la personne qui l'a écrit.

## Signaler

Contactez [@c0remusic](https://github.com/c0remusic) sur GitHub. Les
signalements sont traités de façon confidentielle et reçoivent une réponse
sous 7 jours.

Pour une faille de sécurité, ce n'est pas le bon canal : voir
[SECURITY.md](SECURITY.md).
